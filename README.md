#### Descripción del proyecto

#### Gestor de Tareas SDD es un proyecto de software orientado a la organización y administración de tareas. Su propósito es facilitar el seguimiento de actividades, mejorar la organización personal y ayudar a gestionar las tareas de manera sencilla y eficiente.
